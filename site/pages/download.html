Tải Vikey

Miễn phí · mã nguồn mở · phiên bản VERSION

Hướng dẫn cài đặt

macOS

  1. Mở file vừa tải, kéo Vikey vào thư mục Applications.
  2. Thoát OpenKey, EVKey hoặc bộ gõ khác nếu đang chạy.
  3. Mở Vikey, cấp quyền Trợ năng (Accessibility) khi được hỏi.

SHA-256: SHA256

Windows

  1. Mở file vừa tải. Không cần quyền quản trị.
  2. Thoát OpenKey, EVKey, UniKey hoặc bộ gõ khác nếu đang chạy.
  3. Vikey nằm ở khay hệ thống. Bấm Alt+Z để chuyển Anh/Việt.

Nếu SmartScreen hỏi, bấm "More info" rồi "Run anyway".

Bản không cần cài: x64 (zip) · ARM64 (zip)
SHA-256: WIN_X64_SHA (x64) · WIN_ARM64_SHA (ARM64)

Linux

  1. Cài gói: sudo apt install ./vikey_*.deb (hoặc sudo dnf install ./vikey-*.rpm), rồi đăng xuất và đăng nhập lại.
  2. Vào Cài đặt › Bàn phím › Nguồn nhập, thêm "Vietnamese (Vikey)".
  3. Chuyển sang Vikey bằng Super+Space. Bấm Alt+Z để chuyển Anh/Việt.

Nhớ theo trang web chưa có trên Linux; nhớ theo ứng dụng chỉ với ứng dụng X11 trên Wayland.
