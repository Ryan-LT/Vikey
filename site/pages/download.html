macOS

macOS 13+ · Apple Silicon và Intel · đã được Apple xác thực

Tải cho macOS

Mở trang này trên máy Mac để tải.

  1. Mở file vừa tải, kéo Vikey vào thư mục Applications.
  2. Thoát OpenKey, EVKey hoặc bộ gõ khác nếu đang chạy.
  3. Mở Vikey và cấp quyền Trợ năng (Accessibility) khi được hỏi. Biểu tượng Vikey nằm trên thanh menu.

SHA-256: SHA256

Windows

Windows 10/11 · x64 và ARM64 · không cần quyền quản trị

Tải cho Windows

Máy Windows chạy chip ARM? Tải bản ARM64

Mở trang này trên máy Windows để tải.

  1. Mở file vừa tải. Vikey cài cho tài khoản của bạn, không cần quyền quản trị.
  2. Thoát OpenKey, EVKey, UniKey hoặc bộ gõ khác nếu đang chạy.
  3. Biểu tượng Vikey nằm ở khay hệ thống (góc dưới bên phải). Bấm Alt+Z để chuyển Anh/Việt.

Bản đầu tiên chưa được ký số: nếu SmartScreen hỏi, bấm "More info" rồi "Run anyway". Bản có chữ ký số sẽ ra ngay khi chứng thư được cấp.

Bản chạy ngay, không cài: x64 (zip) · ARM64 (zip)
SHA-256 bản cài: WIN_X64_SHA (x64) · WIN_ARM64_SHA (ARM64)

Linux

Ubuntu, Debian, Fedora · x64 và ARM64 · bộ gõ IBus

Tải .deb (Ubuntu)

Khác: .deb ARM64 · .rpm (Fedora) x64 · .rpm ARM64

  1. Cài gói: sudo apt install ./vikey_*.deb (hoặc sudo dnf install ./vikey-*.rpm), rồi đăng xuất và đăng nhập lại.
  2. Vào Cài đặt › Bàn phím › Nguồn nhập, thêm "Vietnamese (Vikey)".
  3. Chuyển sang Vikey bằng phím nguồn nhập (Super+Space). Bấm Alt+Z để chuyển Anh/Việt.

Nhớ theo trang web chưa có trên Linux; nhớ theo ứng dụng chỉ với ứng dụng X11 trên Wayland.

Mã nguồn và mọi phiên bản đều có trên GitHub. Thay đổi từng bản xem ở lịch sử phiên bản.
