macOS

macOS 13+ · Apple Silicon and Intel · notarized by Apple

Download for macOS

Open this page on your Mac to download.

  1. Open the downloaded file and drag Vikey into the Applications folder.
  2. Quit OpenKey, EVKey or any other Vietnamese input method if one is running.
  3. Open Vikey and allow Accessibility when asked. The Vikey icon is in the menu bar.

Windows

Windows 10/11 · x64 and ARM64 · no admin rights needed

Download for Windows

Windows on an ARM chip? Get the ARM64 build

Open this page on your Windows PC to download.

  1. Open the downloaded file. Vikey installs for your user account, no admin rights needed.
  2. Quit OpenKey, EVKey, UniKey or any other Vietnamese input method if one is running.
  3. The Vikey icon sits in the system tray (bottom right). Press Alt+Z to switch between English and Vietnamese.

This first build is not yet code-signed: if SmartScreen asks, click "More info", then "Run anyway". A signed build follows as soon as the certificate is issued.

Portable, no installer: x64 (zip) · ARM64 (zip)
Installer SHA-256: WIN_X64_SHA (x64) · WIN_ARM64_SHA (ARM64)

Linux

Ubuntu, Debian, Fedora · x64 and ARM64 · IBus engine

Download .deb (Ubuntu)

Other: .deb ARM64 · .rpm (Fedora) x64 · .rpm ARM64

  1. Install the package: sudo apt install ./vikey_*.deb (or sudo dnf install ./vikey-*.rpm), then log out and back in.
  2. Open Settings › Keyboard › Input Sources and add "Vietnamese (Vikey)".
  3. Switch to Vikey with the input-source key (Super+Space). Press Alt+Z to switch English/Vietnamese.

Per-website memory is not available on Linux yet; per-app memory works for X11 apps on Wayland.

The source code and every version are on GitHub. See what changed in each version in the changelog.
