Download Vikey

Version VERSION · macOS 13+ · Apple Silicon and Intel · notarized by Apple

Download for macOS

Open this page on your Mac or Windows PC to download.

  1. Open the downloaded file and drag Vikey into the Applications folder.
  2. Quit OpenKey, EVKey or any other Vietnamese input method if one is running.
  3. Open Vikey and allow Accessibility when asked. The Vikey icon is in the menu bar.
# Check the download shasum -a 256 ~/Downloads/Vikey-VERSION.dmg # expected result: SHA256

Vikey for Windows

Version WIN_VERSION · Windows 10/11 · x64 and ARM64

Download for Windows Windows on ARM

  1. Open the downloaded file. Vikey installs for your user account, no admin rights needed.
  2. Quit OpenKey, EVKey, UniKey or any other Vietnamese input method if one is running.
  3. The Vikey icon sits in the system tray (bottom right). Press Alt+Z to switch between English and Vietnamese.

This first Windows build is not yet code-signed: if SmartScreen asks, click "More info", then "Run anyway". A signed build follows as soon as the certificate is issued.

No installer? Portable build: x64 (zip) · ARM64 (zip). Installer SHA-256: WIN_X64_SHA (x64) · WIN_ARM64_SHA (ARM64).
